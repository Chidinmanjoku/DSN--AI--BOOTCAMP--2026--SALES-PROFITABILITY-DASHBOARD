# DSN AI Bootcamp 2026 — Corrected Sales & Profitability Dashboard

## Project Overview

This project focuses on data cleaning, dashboard auditing, and sales and profitability analysis using Excel and Power BI for the DSN AI Bootcamp 2026 project.

## Corrected Sales & Profitability Dashboard

## Key Findings

- **Total Revenue:** ₦46.68M
- **Total Profit:** ₦14.59M
- **Total Transactions:** 420
- **Return Rate:** 8.6%
- **Top Market by Profit:** Lagos, with ₦4.58M.
- **Top Product Category by Profit:** Electronics, with ₦8.99M.
- **Highest Monthly Revenue:** May 2026, at ₦7.01M.
- **Highest Return Rate by Channel:** WhatsApp, at 11.9%.
